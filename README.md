# GRAE GRAE POTATO 🥔

React + Vite + Three.js 기반의 개인용 인터랙티브 군중 웹아트.

## 실행

1. Node.js 20.19+ 설치
2. 이 폴더에서 터미널 실행
3. `npm install`
4. `npm run dev`
5. 터미널에 표시된 `http://127.0.0.1:5173` 접속

## 기능
- 정면/45도/측면/후면 네 장의 로컬 이미지로 만든 3D 볼륨 머리 군중
- 클릭하면 랜덤 문구, 다시 클릭하면 재추첨 (연속 중복 방지)
- EDIT QUOTES: 한 줄에 문구 하나씩, 브라우저 localStorage 저장
- JSON 가져오기/내보내기
- ADD CHAOS: 10개 추가 (최대 150개), RESET
- 반응형 화면 및 움직임 줄이기 옵션

## 이미지
- `public/images/front.png`, `angle.png`, `side.png`, `back.png`
- 포함된 이미지는 사용자가 제공한 2×2 참고 이미지에서 **자동 타원 마스크로 임시 분리한 것**이므로 머리카락 가장자리와 목 제거가 완벽하지 않음. 더 자연스럽게 하려면 동일 파일명으로 배경이 투명한 정교한 PNG를 교체할 것.
- **중요:** 이것은 정밀한 실사 3D 얼굴 복원이 아님. 3D 타원체와 머리카락 볼륨 위에 4방향 사진 텍스처를 입힌 연출이며, 입 벌리기·화내기 등은 단순 3D 요소를 덧씌우는 방식임. 얼굴 전체 표정이 사진처럼 자연스럽게 변하는 것은 아님. 사실적인 표정 변형을 원하면 얼굴 메시 + 리깅 + 블렌드셰이프를 별도로 제작해야 함.

## 개인정보와 실행
- 얼굴 이미지와 문구를 외부 API로 전송하는 코드는 없음. 로컬 서버는 127.0.0.1에만 바인딩됨.
- `npm install` 시 패키지를 다운로드하므로 네트워크 연결이 필요함.
- 문구는 해당 브라우저의 localStorage에 저장되며 브라우저 데이터를 지우면 사라질 수 있으므로 JSON 내보내기를 활용.
- 실제 인물의 이미지를 포함하므로 외부 공유/배포에 주의.

## 노란 감자 얼굴 & 기억 기반 문구 (수정 버전)
- 4방향 얼굴 PNG의 피부 영역을 황금빛 감자색으로 보정했으며, 머리카락은 최대한 어둡게 유지함. 3D 피부 메시도 노란색으로 변경함.
- `src/main.jsx`의 `DEFAULT_QUOTES`에 `my background_261106.pdf`의 재희 언니 관련 기록에서 짧은 표현 7개를 발췌해 넣음. 정확한 녹취가 아닌 **사용자의 기억에 근거한 표현**임.
- 타인의 민감한 사생활을 포함하는 내용은 기본 문구에 넣지 않았음.
- 기존 브라우저에서 편집한 문구가 있을 경우 새 저장 키(`grae-grae-potato-quotes-v2`)에 기본 문구가 로드됨. 이후 EDIT QUOTES에서 수정하면 저장됨.
- 사진의 피부색을 선택적으로 바꾼 이미지 기반 합성으로, 정확한 실사 3D 복원은 아님.

## 수정 내역 (실행 점검)
- 3D 캔버스가 150px 높이로 고정돼 머리들이 상단 띠에 납작하게 몰리던 문제 → 캔버스가 장면 영역 전체를 채우도록 수정
- 입 애니메이션이 scale을 절대값으로 덮어써 긴 갈색 가시처럼 늘어나던 문제 → 상대 크기로 수정
- 입·눈썹을 각 사진(정면/45도/측면)의 실제 입·눈 위치에 맞춰 곡면 데칼 위에 배치 (0: 평온, 1: 화남+눈썹 씰룩, 2: 소리치기)
- 후면 머리 아래로 노란 피부 구가 삐져나오던 문제 수정
- "그래그래!!!!!!!" 말풍선이 캔버스 뒤로 가려지던 문제 → z-index 추가
- 사진의 흰 배경을 로컬에서 투명 처리(테두리와 연결된 흰 영역만 제거). 원본은 `images-original/`에 보관

## 2.5D 사진 컷아웃 콜라주 (현재 렌더링 방식)
- 구체·노란 덩어리·도형 입/눈썹 메시를 모두 제거. 머리 하나 = 실제 윤곽 PNG 평면 + 흐린 그림자 평면.
- 위 "기능"·"이미지" 절의 3D 타원체/표정 도형 설명은 이전 방식이며 더 이상 해당하지 않음.
- 컷아웃 생성: `python3 tools/cutout.py images-original public/images <미리보기 폴더>` (로컬 전용, numpy·scipy·Pillow 필요). 테두리와 이어진 흰 배경만 제거하고, 사진별로 따라 그린 턱선 아래의 피부(목)를 제거함.
- 한계: 원본 4장이 이미 타원으로 잘려 있어 머리카락 끝(아래쪽)과 측면 사진의 뒤통수 일부는 그 잘린 선에서 부드럽게 사라짐. 턱선은 사진을 보고 수동으로 지정한 좌표라 몇 픽셀 오차가 있을 수 있음.
